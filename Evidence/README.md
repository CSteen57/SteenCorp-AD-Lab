# Evidence

This directory contains screenshots documenting and validating each stage of the SteenCorp Enterprise IT Lab.

## Structure

- `Infrastructure`: Active Directory setup, OU structure, security groups, administrative accounts, and file shares
- `Automation`: PowerShell deployment, bulk user provisioning, employee onboarding, and script validation
- `Networking`: DHCP, DNS, IP addressing, VMware networking, and connectivity troubleshooting
- `Phase2_Chrome_GPO`: Google Chrome deployment through Group Policy and client-side installation validation
- `Validation`: Domain logins, mapped drives, permissions, networking, security controls, and other client-side testing

Each image is referenced in the appropriate project phase documentation to connect the configuration work with its supporting evidence.
